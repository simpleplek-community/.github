# SimplePlek Community

Welcome to the **SimplePlek community**.

We're building a flexible platform for managing bookings and reservations across different types of real-world resources.

## 🏗️ What we're building

SimplePlek explores reusable booking infrastructure that can support different use cases, including:

* 🏠 **Short-term accommodation**
* 💼 **Workspace hire**
* 🏢 **Offices and meeting rooms**
* 📅 **Other time-based reservations**

The goal is to build booking infrastructure that can adapt to different types of resources rather than creating a separate system for every use case.

## 📦 Projects

### [Bookings](https://github.com/simpleplek-community/bookings)

The core booking project for managing availability, reservations and booking workflows.

It currently supports use cases including **short-term accommodation and workspace hire**.

More projects will be added as the ecosystem develops.

This is a community-driven project, and discussions are an important part of how we develop it.

* 💡 Share ideas
* 🧭 Discuss the roadmap
* 🛠️ Talk about architecture and development
* 🐛 Ask questions and get help
* 📋 Propose larger changes through RFCs
* 🔌 Discuss integrations

## 🤝 Contributing

You don't need to be a core developer to participate.

You can contribute by:

* sharing an idea
* describing a use case
* asking a question
* helping another community member
* improving documentation
* reporting a problem
* contributing code

When a discussion develops into something we want to build, it can move into an issue and eventually a pull request.

## 🌱 Early stage

SimplePlek is evolving.

The architecture, features and direction will develop through experimentation, implementation and community discussion.

If you work with bookings, accommodation, workspaces, scheduling or resource management — or simply have an idea you'd like to explore — you're welcome here.
