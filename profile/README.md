# SimplePlek Community

Welcome to the **SimplePlek community**.

We are building an open platform for managing bookings and reservations across different types of real-world resources.

## 🏗️ What we're building

The SimplePlek ecosystem is designed around a flexible booking model that can support different use cases, including:

* 🏠 Short-term accommodation
* 💼 Workspace hire
* 🏢 Offices and meeting rooms
* 📅 Other time-based reservations

Rather than building separate booking systems for every use case, we're exploring reusable infrastructure that can support them all.

## 📦 Projects

### [Bookings](https://github.com/simpleplek-community/bookings)

The core booking application and infrastructure for managing availability, reservations and booking workflows.

The project currently explores both **short-term accommodation** and **workspace hire**.

More projects will be added as the ecosystem develops.

## 🤝 Contributing

You don't need to be a core developer to participate.

Use Discussions to share a use case, ask a question, propose an idea or start a conversation.

When an idea becomes something we want to build, we can turn the discussion into an issue and eventually a pull request.

## 🌱 Early stage

SimplePlek is evolving.

The architecture, features and direction are expected to develop through experimentation and community discussion.

If you have an idea for how booking, availability or resource management could work better, we'd like to hear it.
